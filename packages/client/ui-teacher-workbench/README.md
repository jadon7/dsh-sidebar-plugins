# @deepseek-ai/dsh-client-ui-teacher-workbench

English | [中文](README.zh.md)

Browser-only teacher workbench mockup. The plugin contributes a `sidebar.footer.action` entry and opens six interactive teaching views over the main area: schedule, lesson plans, students, family communication, classroom tools, and professional growth. All content, integrations, and actions are local UI state.

## Model Experience

No direct model surface. The AI co-planning area is a local interface mockup.

#### KV Cache effect

None.

## Known Limitations and Deferred Work

- Persistence, real DSH conversations, school data, and third-party integrations are not implemented.
