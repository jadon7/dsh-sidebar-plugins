# @deepseek-ai/dsh-client-ui-token-poker

English | [中文](README.zh.md)

Browser-only Token poker mockup. The plugin contributes a `sidebar.footer.action` entry and opens an interactive six-seat poker table over the main area. All players, cards, token stacks, and actions are local UI state; it has no network, wallet, or game service.

## Model Experience

No direct model surface. The plugin renders browser UI only.

#### KV Cache effect

None.

## Known Limitations and Deferred Work

- Multiplayer, persistence, and real token accounting are not implemented.
