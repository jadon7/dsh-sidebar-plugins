三条原则
① 钱的动作要看得见 —— 筹码必须真的飞过去，底池数字必须滚，不能直接跳。
② 牌永远从牌靴方向进场（左上），不要从屏幕边缘乱飞。
③ 状态类变化（回合、禁用）一律 160–180ms，快到几乎无感；只有钱和牌值得 300ms 以上。
实现注意
翻牌用 rotateY + backface-visibility:hidden 双面，别做两张牌淡入淡出——牌背的菱格织纹在淡出时会糊成一团。父级要给 perspective:900px，否则翻转是平的。全部动效只用 transform / opacity / box-shadow，不要动 width / top。
