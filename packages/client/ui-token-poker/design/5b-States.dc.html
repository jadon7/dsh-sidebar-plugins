5b Token 德州 · 牌局状态全集

全部 11 屏都由同一个组件 Poker-Table 渲染，切 state 一个属性即可。翻牌 是 5a-C 定稿那一帧，其余 10 屏在它之上只改数据、不改布局。四色牌可用 fourColorDeck 关掉换回传统双色。

黑 / 蓝 标签是黑色或蓝色（蓝＝定稿基准）的画面，文案与数据能对上仓库里的 locales.ts / PokerPanel.tsx。
红标 净新增流程，源码里还不存在，文案是设计提案，需要产品先拍板再实现。11 屏里只有 flop 和 invite 是纯换皮，其余 9 屏都要新增状态逻辑。
一 · 牌局进程 公共牌翻开数量 0 / 3 / 4 / 5，底池与快捷下注默认值随街递进
preflop 翻牌前 5 张牌背，小盲 500K + 大盲 1M 已在池，底池 1.5M
flop 翻牌 · 5a-C 定稿 基准帧，所有间距色值以此为准
turn 转牌 无人下注 → 跟注按钮收起，只剩弃牌 / 下注
river 河牌 五张全开，K♦ 是满色卡面
二 · 回合与下注 谁的回合，以及余额顶到上限时的处理
waiting 等别人回合 你已下注 1.28M（底池 1.7M → 2.98M，桌上多一枚你的筹码）→ 弃牌/跟注收起，主按钮变「等待中」；Kai 挂 12s 倒计时环
allin 筹码不足 · 只能全下 滑杆锁 100%，主按钮转珊瑚色「全下」，跟注按钮消失
showdown 亮牌结算 · 赢家高亮 未弃牌的人翻出 30×42 小牌，弃牌的降到 45% 挂「已弃牌」
三 · 座位与弹窗 弹窗统一 rgba(10,12,22,.66) + 3px 模糊遮罩，卡片圆角 26
empty 空座位 1.5px 虚线框 + 就地「邀请」按钮，顶部在线数同步
invite 邀请好友 · 已复制 源码里这不是弹窗：头部按钮切到 invited 态，文案换成「房间码已复制」
leave 离开确认 净新增 · 源码里 ESC / 离开是直接关闭，没有二次确认
reconnect 断线重连 / 加载中 净新增 · 源码里没有这个流程，文案待产品确认
